# Marine Dynamics Logistics — Freight Forwarding Web App

A sleek, responsive, and modern freight forwarding website built using **React.js** and **Tailwind CSS**. Showcases core logistics services, provides an interactive experience, and delivers a clean, professional UI designed for global shipping businesses.

## 🛠 Getting Started

To run this project locally:

1. Clone this repository or download the source code.
2. Navigate into the project directory and open it in your preferred code editor.
3. Ensure you have **Node.js** and **npm** installed.
4. Install dependencies by running:
   ```bash
   npm install
   ```
5. Start the development server:
   npm run dev
6. Open the local development URL (usually http://localhost:5173) in your browser.

## ✨ Features

This project includes:

- Modern and responsive freight forwarding website layout built with React.js.
- Interactive Get a Quote form for shipment details and inquiries.
- Service sections for Air Freight, Sea Freight, Road Transport, and manymore.
- Clean navigation bar with responsive design and transition effects.
- Optional carousels for testimonials or partners using Swiper.js.
- Fully responsive design for desktop, tablet, and mobile devices.

## 🧰 Technologies Used

- **React.js** – Component-based structure and dynamic UI.
- **Tailwind CSS** – Styling, layout, spacing, and responsive design utilities.
- **JavaScript (ES6+)** – Logic, interactivity, and dynamic behavior.
- **React Router** – Routing and navigation.
- **Swiper.js** - Interactive and responsive carousel functionality.
